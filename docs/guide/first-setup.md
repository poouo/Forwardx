# 首次初始化

浏览器打开面板地址：

```text
http://服务器IP:9810
```

全新部署首次访问会进入初始化向导。安装脚本可能已预填数据库类型和连接参数，核对后继续；复用已有数据库时使用原管理员账号登录，不会重新创建管理员。

## 界面语言

安装脚本支持 `--language zh-CN`、`--language en`、`--language auto`。中文 README 的安装命令默认传入中文，英文 README 默认传入英文。也可通过 `FORWARDX_SETUP_LANGUAGE` 环境变量传入，脚本会将其保存到部署目录的 `.env`；升级时保留原值。

首次部署未手动选择语言时，优先使用安装参数，再按浏览器语言 / 已有 IP 地区提示选择。向导右上角提供简体中文和 English 切换，切换后界面直接更新、保留已填写的内容，用户选择保存在浏览器本地并优先生效。初始化完成后，自动模式恢复按浏览器 / IP 判断，不再由安装参数覆盖。

## 第一步：选择数据库

ForwardX 支持三种数据库：

| 数据库 | 适合谁 | 需要提前准备 |
| --- | --- | --- |
| SQLite | 新手、小规模、单机使用 | 不需要，面板自动使用本地数据文件 |
| MySQL | 生产环境、长期使用、多用户 | MySQL 8.0.13 或以上版本、账号和数据库 |
| PostgreSQL | 已有 PostgreSQL 环境的用户 | PostgreSQL 12 或以上版本、账号和数据库 |

选择建议：

- 不确定怎么选，可以先使用 SQLite，并建立可靠备份。
- 后续切换数据库必须按支持的导出、导入流程验证；修改连接不等于自动迁移数据。在线无缝面板迁移要求两端数据库类型一致，见 [数据库配置](./database.md) 和 [面板迁移](./migration.md)。
- 已有现成数据库服务器的，直接选对应类型即可。

SQLite 不需要填写连接信息，面板会自动管理本地文件。

MySQL 和 PostgreSQL 需要填写：

- 数据库地址
- 端口
- 用户名
- 密码
- 数据库名
- 是否启用 SSL

填写完成后先点击"测试连接"，连接成功后才能继续。

::: tip Docker 用户
面板通过 Docker 部署时，数据库地址要填写面板容器内部能访问到的地址。数据库在同一个 compose 网络中时，填写数据库服务名；数据库在宿主机上时，填写宿主机内网 IP。不要直接填 `127.0.0.1`，那会指向容器自身。
:::

::: warning 连接失败排查
容器日志出现 `getaddrinfo ENOTFOUND 数据库地址` 时，说明面板容器无法解析该主机名。检查数据库容器和面板容器是否在同一 Docker 网络，或改用面板能直接访问的 IP/域名。
:::

## 第二步：创建管理员账号

数据库连接成功后，创建第一个管理员账号，填写管理员邮箱、密码并再次确认密码即可。管理员邮箱登录时不区分大小写。

管理员拥有完整权限，包括：

- 管理用户和套餐计费
- 管理主机和 Agent
- 管理转发规则、链路、隧道、转发组
- 配置系统设置、Telegram / Discord 通知、邮件、Google 登录与 DDNS
- 执行面板和 Agent 升级

创建完成后用该账号登录面板。

## 第三步：设置面板公开地址

登录后第一时间进入：

```text
系统设置 -> 系统配置
```

填写"面板公开地址"。

![在系统信息中填写 Agent 实际可访问的面板公开地址](./images/setup-public-address.png)

没有域名时填写：

```text
http://服务器IP:9810
```

已配置 HTTPS 域名时填写：

```text
https://panel.example.com
```

::: warning 必须完成此步骤
面板公开地址直接影响 Agent 安装脚本生成、Agent 自动升级和 Agent 与面板的通讯。仅修改此项不会让仍连接旧 URL 的离线 Agent 自动回连。后续变更地址需保留旧入口、按迁移流程转交，或在 Agent 主机更新连接地址；需要保持业务连接时先阅读 [迁移说明](./migration.md)。
:::

## 第四步：创建 Agent Token

Agent Token 用于让服务器注册到当前面板。进入：

```text
主机管理 -> Token 管理
```

点击"添加 Token"，填写名称后保存。

Token 创建完成后，点击对应 Token 的"安装命令"，面板会生成包含该 Token 和面板地址的一键安装命令。复制命令后在需要管理的 Linux 服务器上执行，Agent 即可自动注册上线。

安装命令格式类似：

```bash
curl -fsSL http://你的面板地址:9810/api/agent/install.sh | bash -s -- install YOUR_AGENT_TOKEN
```

::: tip
一个 Token 只绑定一台服务器；需要接入多台服务器时，请分别创建 Token。独立 Token 不影响主机加入入口组、出口组或转发组。安装后在「主机管理」页面看到绿色在线状态，说明 Agent 已成功连接面板。
:::
