# UI 精简检查记录

本轮沿用 React / Wouter / 原有组件架构，独立 Vue 预览入口、构建命令及源码已撤回；试验源码备份在项目外。没有修改转发、Agent、计费、权限和数据库逻辑。

## 已实施

- 删除重复的页头介绍和卡片说明，不用全局 CSS 隐藏文案。
- 页头由厚重容器改为标题、操作区与轻分隔线，减少重复边框和阴影。
- 卡片默认标题收敛到正文层级以上，保留各页面的字号覆盖；弹窗标题和说明左对齐、允许长词换行，避开关闭按钮。
- 次要技术说明使用原生可点击折叠块，支持键盘和触屏，不依赖悬浮提示，不卸载其中的内容。
- AI、Google 账号、通知绑定、单条规则限额、迁移条件和探测统计口径采用上述说明层级；关键操作影响仍在正文或确认弹窗展示。
- 简化批量管理、主机流量故障转移、分页和部分保存按钮文案；保留规则归属、限额含义、当前页、总数和分页操作。
- 同步英文短文案，修正新建链路类型在切换语言后未更新的静态标签，补齐链路视图按钮的名称与选中状态。
- 支付状态徽章取消固定浅色底，余额入账金额补充深色文字配色，改善暗色主题下的突兀亮块和低对比。
- 保留现有卡片、标签滑动、内容切换与折叠动效；没有新增动画依赖。

## 刻意保留的内容

删除/清空/解绑的实际影响、插件高权限授权、迁移与恢复风险、端口与协议兼容性、HTTPS/验证码条件、流量计算方式、计费单位、限额和有效期、用户自定义说明、原始测试输出及错误原因。

不通过截断、缩小到难以阅读或省略号隐藏这些信息，不更改用户输入和业务字段。

## 后续值得继续优化

1. 密集规则/主机卡片可进一步将低频字段移到详情区，默认优先展示状态、路由、流量和核心操作；应结合真实用户数据截图确认，而非统一隐藏字段。
2. 主机、规则和链路的筛选条可进一步统一搜索、作用范围、筛选数量与清除入口；涉及既有筛选习惯，建议单独验证交互。
3. 重型地图/地球视图继续按需加载；当前构建仍有既有大包警告，适合独立做前端拆包，不宜混入纯文案调整。
